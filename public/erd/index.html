PK=기본키, FK=외래키, UK=유일키입니다. UK1 같은 표시는 여러 열을 묶은 복합 유일키이며, 각 열이 단독으로 유일하다는 뜻이 아닙니다. NULL 허용 UNIQUE 열에는 여러 NULL이 들어갈 수 있습니다. 기본값·허용 값·CHECK 조건을 각 테이블에서 확인할 수 있습니다.

1:1 변환 방식 (강의 415–417쪽)
PAYMENT.reservation_id는 NOT NULL + FK + UK로 결제당 예약 1건, 예약당 결제 최대 1건을 보장합니다. REVIEW.reservation_id는 NULL 허용 + FK + UK로 연결된 예약당 후기 최대 1건을 보장합니다. 예약–후기는 양쪽 선택 참여의 일반형(규칙 4-1: 외래키 상호 교환)과 다르게 REVIEW 한쪽에만 외래키를 둔 설계 선택입니다. 순환 참조를 피하기 위한 차이이며, 상세 테이블 정의서에 근거를 기록했습니다.
