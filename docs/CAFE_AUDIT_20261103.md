# 누락 지역 스터디카페 재조회 (2026-11-03)

카카오맵 Places API를 공식 JavaScript SDK로 호출했다. 이전에 수집된 카페가 없던 22개 지역에 대해 지역명·주소 별칭과 스터디카페/스터디 카페/독서실/스터디룸 검색어, 지역 경계 검색을 조합해 173회 조회했다. 독서실 검색은 누락 후보 발견용이며 독서실 자체를 서비스에 추가하기 위한 것이 아니다.

검색 결과가 없다는 것은 이 조회에서 확인하지 못했다는 뜻이다. 해당 지역에 실제 스터디카페가 없다고 판단하지 않는다. 타 지역 주소 결과는 제외했다.

## 추가한 스터디카페

| 지역 | 매장 | 확인 근거 |
|---|---|---|
| 충청남도 태안군 | 하자스터디카페 | [카카오 장소](https://place.map.kakao.com/780331703): 이름·주소·매장 링크와 스터디카페 이용 후기 확인 |
| 경상남도 의령군 | 그램스터디카페 | [카카오 장소](https://place.map.kakao.com/3905451), [브랜드 공식 의령행복점](https://gramstudy.com/bri/board.php?bo_table=branches&wr_id=16): 행복로 14 주소 일치 |

두 매장은 카카오에서 독서실로 분류되어 기존 이중 필터에 걸렸다. 이름에 스터디카페가 명시된 매장은 학원·공유오피스·모임공간이 아닌 경우 허용하도록 수정했다. 매장 요금과 실제 좌석 수는 확인하지 않았으므로 기존 프로젝트와 동일한 **예시 가격·좌석**으로 등록한다. 기존 카페·회원·예약은 수정하지 않는다.

## 잔여석·시연 데이터

- 잔여석은 선택한 날짜·시간에 이 사이트 DB에 저장된 예약과 등록 좌석 수로 계산한다. 실제 매장 출입·키오스크와 연결된 실시간 잔여석이 아니다.
- 가상 예약 300건은 2026-11-03부터 11-10까지 234개 지역에 분산했다. 가상 사용자와 모의 결제이며 실제 결제·문자 발송은 없다. 새로 추가한 두 지역에 추가 예약을 중복 생성하지 않는다.
- 운영 DB 초기화나 다른 프로젝트 테이블 변경 없이 기존 스키마의 카페·좌석·예시 요금만 추가한다.
- 예약·취소·로그인 변경 뒤 목록과 상세의 좌석 캐시를 무효화한다. 조회 실패 시 빈 좌석으로 표시하지 않는다.
